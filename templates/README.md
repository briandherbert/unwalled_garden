# Optional templates

Reuse existing documentation before copying these files. Replace bracketed fields with observed facts or an explicit `unknown`; omit irrelevant sections. Adapt links to your actual project. No particular file count is required.

- [AGENTS.md](AGENTS.md): continuing guidance and context discovery.
- [PROJECT.md](PROJECT.md): durable goals and decisions.
- [HANDOFF.md](HANDOFF.md): current state and next action.
- [PORTABILITY.md](PORTABILITY.md): dependencies, exit paths, and adoption provenance.

The [adoption procedure](../UNWALL.md) defines behavior. Templates are examples, not extra requirements.
